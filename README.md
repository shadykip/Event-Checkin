# Event Invitation & QR Check-in

A web application for organizers to invite guests and for door staff to verify QR passes and record attendance.

## Planned structure

- `apps/web` — Next.js frontend for organizers, guests, and door staff.
- `apps/api` — NestJS API for events, invitations, and check-in.
- PostgreSQL — application database, managed locally with Docker Compose.
